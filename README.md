## 项目介绍

个人基金组合的全流程自动化管理套件。系统由以下**三大核心模块**协同运作，兼顾“日间战术异动响应”与“长期稳健复利管理”：

1. **盘中异动监控与实时看板**：
   - **云端免开机巡检**：交易时间内（09:30-15:00）每 15 分钟由 GitHub Actions 自动巡检 Notion 持仓涨跌，涨跌偏离阈值时自动通过 Bark 向手机推送告警，无需电脑开机或网页常驻。
   - **多端实时看板**：基于 GitHub Pages 构建轻量纯静态看板，Bark 通知可一键直达，支持多端自适应，并可通过 Notion 的 `/embed` 块直接内嵌在投资主页中实时交互预览。
2. **盘后每日归档与再平衡建议**：
   - **收盘净值自动同步**：每个工作日收盘后（19:00 CST）自动抓取天天基金官方确认净值（T+1），自动归档沉淀至 Notion 数据库。
   - **科学调仓与温度计**：基于设定的股债目标比例自动计算配置偏差与调仓金额，结合沪深 300、中证 A500、国债收益率与股债利差给出量化再平衡建议与市场估值温度。
3. **快捷指令截图流水记账**：
   - **截图自动化提取**：截取手机支付宝/微信基金买入、卖出或分红页面，通过 iOS 快捷指令提取文本并触发 Actions 导入。
   - **现金流精准沉淀**：自动解析确认金额、确认份额、净值与手续费，自动去重并更新 Notion 交易流水，为未来精准计算 XIRR 真实年化收益率留存全量数据。

如果需要让 Codex 进一步解释基金理财知识、结合知识库做组合复盘、制定定投或再平衡执行计划，请参考 [Codex Finance Assistant](docs/codex-finance-assistant.md)。

## 核心架构：双轨数据同步机制

为满足“长期稳健资产严密监控”与“短期自选观察灵活轻量”的不同需求，本项目设计了**双轨分离同步架构**：

```
┌────────────────────────────────────────────────────────┐
│  Notion 数据库（核心资产主仓）                           │
│  • 债券 / 股票核心资产配置表                             │
│  • 记录持有份额、目标占比、再平衡历史                     │
└───────────┬────────────────────────────────┬───────────┘
            │ 1. 交易日定时读取 (15分钟/次)     │ 2. 每日同步自动导出
            ▼                                ▼
┌───────────────────────────┐    ┌───────────────────────────┐
│ GitHub Actions 云端哨兵   │    │ 静态数据 funds.json       │
│ • 无需开网页、无需唤醒电脑 │    │ • 仅包含公开代码/名称/分类 │
│ • 涨跌超阈值自动 Bark 推送 │    │ • 随 GitHub Pages 自动部署 │
└───────────┬───────────────┘    └─────────────┬─────────────┘
            │                                  │
            │ 3. 通知附带直达看板链接             │ 4. 打开时自动拉取合并
            ▼                                  ▼
┌────────────────────────────────────────────────────────┐
│  GitHub Pages 实时看板（含 Notion 内嵌 /embed 预览）      │
│  • [Notion主仓]：全自动同步自数据库，Notion 新增此处即显示 │
│  • [自选观察]：网页端随手添加，仅存本地浏览器，不污染 Notion │
└────────────────────────────────────────────────────────┘
```

### 1. Notion 核心主仓：自动同步与云端哨兵
- **数据归属**：Notion 基金持仓数据库是唯一的真实数据源。
- **云端免运维巡检**：工作日 09:30-15:00 期间，GitHub Actions 定时运行 `fund_intraday_alert.py`，直接查询 Notion API 获取最新持仓，无需打开任何网页；触发阈值时直接通过 Bark 推送通知至手机。
- **看板自动更新**：每日收盘更新或手动触发同步时，脚本自动将 Notion 持仓导出为轻量、公开的 `fund-alert-pages/data/funds.json`。网页看板每次打开时自动同步，**在 Notion 中增加或修改基金，看板全自动同步**。

### 2. 网页端自选观察：本地沙箱隔离
- **轻量观察**：在网页端点击「+ 添加自选基金」，输入 6 位代码即可实时查看估值与走势。
- **零污染**：自选基金标记为 `[自选观察]`，数据**仅存储在当前浏览器的 `localStorage` 中**，绝不反向写回 Notion，不污染长期复利核心资产库。

## 投资策略说明

本项目基于**固定比例再平衡**策略，将资产分为两层：

| 资产层 | 说明 | 示例 |
|--------|------|------|
| 债券层 | 稳定收益，低波动 | 纯债基金 |
| 股票层 | 长期增值，承受波动 | 指数基金、ETF |

**核心思路：**

1. **设定目标比例** — 根据自身风险承受能力，为每只基金设定目标占比（如债券 40%、股票 60%），填入 Notion 的「目标占比」字段
2. **每日自动监控** — 脚本每天计算各基金实际占比与目标的偏差（「目标差值」= 实际市值 − 目标市值）
3. **偏离触发提醒** — 某只基金偏离目标超过 **5%** 时，自动标记「建议买入」或「建议卖出」
4. **手动执行调仓** — 收到提醒后，按「目标差值」的金额买入或卖出对应基金，将比例拉回目标

**为什么要再平衡？**

市场涨跌会使各资产的实际占比逐渐偏离初始设定。定期再平衡的本质是「高卖低买」——股票涨多了就卖掉一些补到债券，债券涨多了就卖掉一些补到股票，长期下来有助于控制风险并改善收益。

## 主要特点

- **盘中预警提醒** — 交易日盘中每 15 分钟通过 GitHub Actions 自动巡检估值，涨跌超预设阈值自动走 Bark 发送通知
- **直达看板链接** — Bark 通知携带专属 URL，手机轻点横幅通知直接拉起 Safari 打开实时看板
- **在线估值看板** — 部署于 GitHub Pages，支持多设备访问，支持恢复默认持仓与本地自定义调控
- **Notion 嵌入预览** — 支持在 Notion 父页面中作为原生 `/embed` 块内嵌展示，并在每日同步时自动挂载，一眼看全盘中动态
- **自动更新净值** — 每个工作日晚上 7 点通过 GitHub Actions 自动运行，拉取天天基金最新确认净值（T+1）
- **实时配置比例** — 自动计算每只基金的实际持仓占比，与目标占比对比
- **再平衡提醒** — 偏离目标超过 5%（可配置）时，标记「建议买入」或「建议卖出」并显示调仓金额
- **市场估值温度** — 每日抓取沪深 300、中证 A500（参考中证 500）PE 值，低估 🟢 / 正常 🟡 / 高估 🔴
- **策略说明保留** — 自动维护 Notion 数据库描述区和父页面正文的长期配置说明，采用隔离标桩精准替换市场温度
- **完全 Notion 集成** — 净值、涨跌幅、盈亏、建议均写入 Notion 数据库，支持表格和饼图视图
- **交易流水记录** — 支持把支付宝基金截图 OCR 文本写入 Notion「交易流水」，为后续 XIRR 年化收益率计算保留现金流
- **截图导入去重** — 买入 / 卖出记录优先按订单号去重；待确认记录确认后会更新原记录，已确认记录重复导入会跳过
- **零运维 & 秒级运行** — GitHub Actions 免费定时调度，盘中监控剥离重型依赖，依赖安装压缩至 1 秒级

## Notion 数据库字段说明

### 基金持仓

| 字段 | 类型 | 说明 |
|------|------|------|
| 基金名称 | 标题 | 基金名称 |
| 基金代码 | 文本 | 天天基金代码 |
| 资产层 | 选择 | 债券层 / 股票层 |
| 持有份额 | 数字 | **手动填写**，交易后更新 |
| 当前净值 | 数字 | 自动更新 |
| 今日涨跌幅 | 百分比 | 自动更新 |
| 今日盈亏 | 公式 | 自动计算（现有资产 × 今日涨跌幅） |
| 现有资产 | 公式 | 自动计算（持有份额 × 当前净值） |
| 配置比例 | 百分比 | 自动更新（当前市值 / 总市值） |
| 目标占比 | 文本 | 手动填写，如 `40%` |
| 目标差值 | 元 | 自动更新（正值=超配，负值=低配） |
| 操作建议 | 选择 | 自动更新：持有 / 建议买入 / 建议卖出 |
| 估值信号 | 选择 | 自动更新：低估 / 正常 / 高估 / 暂无 |
| 定投建议 | 选择 | 自动更新：暂停 / 50% / 100% / 150% / 200% |
| 更新时间 | 文本 | 自动更新 |

### 交易流水

交易流水用于记录买入、卖出、分红、份额调整和持仓快照。它不是当前持仓状态表，而是后续计算真实年化收益率（XIRR）的现金流与审计记录。

| 字段 | 类型 | 说明 |
|------|------|------|
| 交易名称 | 标题 | 自动生成，如 `2026-06-08 南方纳斯达克100指数A 买入` |
| 日期 | 日期 | 买入 / 卖出 / 截图记录日期 |
| 基金 | 关联 | 关联到「基金持仓」中的对应基金 |
| 类型 | 选择 | 买入 / 卖出 / 分红 / 份额调整 / 持仓快照 |
| 状态 | 选择 | 已确认 / 待确认 / 已同步 |
| 金额 | 数字 | 买入为负数，卖出 / 分红为正数，持仓快照为 0 |
| 份额变动 | 数字 | 买入确认份额为正，卖出份额为负 |
| 持有份额快照 | 数字 | 资产详情截图中的当前持有份额 |
| 确认净值 | 数字 | 交易确认净值或截图中的基金净值 |
| 确认金额 | 数字 | 交易确认金额 |
| 手续费 | 数字 | 交易手续费 |
| 确认日期 | 日期 | 基金确认日期 |
| 订单号 | 文本 | 支付宝交易订单号，用于去重 |
| 来源 | 选择 | 如 支付宝截图 |
| 去重键 | 文本 | 脚本生成，用于防止重复导入 |
| OCR原文 | 文本 | 原始 OCR 文本，便于排查解析问题 |

## 使用方法

### 1. 准备 Notion

1. 在 [notion.so/my-integrations](https://www.notion.so/my-integrations) 创建一个内部集成，复制 Token（`ntn_xxx` 或 `secret_xxx`）
2. 打开你的 Notion 数据库页面，点击右上角 `...` → `连接` → 选择刚创建的集成
3. 在数据库中填写每只基金的**持有份额**和**目标占比**

### 2. 本地运行

```bash
git clone https://github.com/guoyingwei6/fund-monitor.git
cd fund-monitor
pip install -r requirements.txt

export NOTION_TOKEN=你的token
python fund_monitor.py
```

### 3. GitHub Actions 自动运行

1. Fork 或 push 到你自己的 GitHub 仓库
2. 进入仓库 **Settings → Secrets and variables → Actions**
3. 添加 Secrets 环境变量：
   - `NOTION_TOKEN`：你的 Notion 集成 Token（用于读取持仓和盘后同步）
   - `BARK_URL`：你的 Bark 推送地址（形如 `https://bark.example.com/your_key/`，用于盘中异动通知）
4. 系统自动调度两条核心流水线：
   - **盘中异动监控** (`intraday_alert.yml`)：交易日 09:30-15:00 每 15 分钟自动巡检持仓，超阈值时向 Bark 发送通知。
   - **盘后净值更新** (`daily_update.yml`)：每个工作日 19:00 CST 自动拉取收盘确认净值、同步再平衡与市场温度、自动更新 Notion 父页面 Embed 实时看板。

### 4. 可选配置

在 GitHub Actions 的 workflow 文件或本地环境变量中设置：

```bash
# 再平衡触发阈值，默认 5%（偏离超过此值才提示调仓）
export REBALANCE_THRESHOLD=0.05

# 盘中异动监控默认阈值（单位：百分比，如 1.5 表示 ±1.5%）
export ALERT_THRESHOLD_UP=1.5
export ALERT_THRESHOLD_DOWN=1.5

# 盘中实时看板部署地址（用于 Bark 推送直达跳转与 Notion 嵌入）
export PAGES_URL=https://guoyingwei6.github.io/fund-monitor/
```

定投建议不会改变长期目标占比，只用于调节新增资金。执行优先级是先看「操作建议」，再看「估值信号」：

| 操作建议 | 估值信号 | 定投建议 |
|----------|----------|----------|
| 建议卖出 | 任意 | 暂停 |
| 建议买入 | 低估 | 200% |
| 建议买入 | 正常 / 暂无 | 150% |
| 建议买入 | 高估 | 50% |
| 持有 | 低估 | 150% |
| 持有 | 正常 / 暂无 | 100% |
| 持有 | 高估 | 50% |

### 5. 记录支付宝截图交易

项目提供 `record_trade_from_ocr.py` 和 GitHub Actions workflow `record_trade.yml`，用于把支付宝基金截图 OCR 文本写入 Notion「交易流水」。

支持两类截图：

1. **交易详情截图**：包含买入金额、确认份额、确认净值、手续费、订单号等字段，会记录为真实现金流，用于后续 XIRR 计算。
2. **资产详情截图**：包含持有金额、持有份额、基金净值、持有收益等字段，会记录为「持仓快照」，不作为真实买入 / 卖出现金流。

如果同一订单号已经存在，脚本会按状态处理：

- 旧记录是 `待确认`，新截图是 `已确认`：更新原交易记录，补齐确认金额、确认份额、确认净值、手续费和确认日期，并更新持仓份额
- 旧记录已经是 `已确认`：跳过，避免重复记录和重复加份额

本地测试：

```bash
export NOTION_TOKEN=你的token
export NOTION_DATABASE_ID=基金持仓数据库ID
export NOTION_TRADES_DATABASE_ID=交易流水数据库ID

# 先只解析，不写入 Notion
python record_trade_from_ocr.py --ocr-file ocr.txt --dry-run

# 写入交易流水，并在适合时更新基金持仓份额
python record_trade_from_ocr.py --ocr-file ocr.txt

# 导入历史截图时，只写交易流水，不更新当前持仓份额
python record_trade_from_ocr.py --ocr-file ocr.txt --no-update-holdings
```

手机快捷指令流程：

1. 截取支付宝基金详情或交易详情页面
2. 用 iOS 快捷指令「从图像中提取文本」
3. 将 OCR 文本通过 GitHub API 触发 `record_trade.yml`
4. GitHub Actions 调用脚本解析文本并写入 Notion

## 数据来源说明

| 数据 | 来源 | 说明 |
|------|------|------|
| 基金净值 | 天天基金（东方财富）API | 每日收盘后约 18:00 更新，T+1 确认净值 |
| 沪深 300 PE | akshare / 乌龟量化 | 滚动市盈率（TTM） |
| 中证 A500 PE/PB | akshare / 乌龟量化 | 暂以中证 500 PE/PB 作近似参考，页面显示为「中证A500参考(中证500)」 |
| 港股温度 | akshare / 乐咕恒生股息率 + 新浪恒生日线 | 股息率月度更新，250 日线交易日更新 |
| 纳指温度 | akshare / 新浪纳斯达克 100 日线 | 用 250 日线和近一年回撤作趋势温度 |
| 债券温度 | akshare / 中国 10 年国债收益率 | 用近 5 年收益率分位判断债券贵贱 |

市场温度区会并列展示债券、港股、中证 A500、纳指四类资产的温度信号；PE/PB 行保留为原始估值指标。

> 所有数据均来自公开接口，无需注册或付费。
